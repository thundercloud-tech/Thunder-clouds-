IMPORTANT: Upload the CONTENTS of this folder to the ROOT of your GitHub Pages repository. Keep the assets folder exactly as supplied; it contains thundercloud-logo.png. Do not upload only index.html.

Firebase setup:
1. In login.html and account.html, replace YOUR_EXISTING_API_KEY with the Web API key from Firebase Project Settings > General > Your apps > SDK config.
2. Enable Email/Password in Firebase Authentication.
3. Add your GitHub Pages domain to Authentication > Settings > Authorized domains if it is not already listed.
4. Never publish Firebase Admin SDK service-account private keys.

Navigation: The ☰ button is the WEBSITE mobile navigation control and opens the separate page links. The vertical three-dot icon shown in a mobile browser is browser UI and cannot be removed by website HTML/CSS.
